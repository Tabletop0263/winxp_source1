# Wii SD Card Layout for XP (NT 5.1) Broadway/G3 Kernel Testing

Exact file layout on the FAT32 SD card (root = sd:/):

sd:/apps/arcldr/boot.dol   - entii arcldr loader (DOL). Launched from the
                              Homebrew Channel. Copied by CI from
                              entii/arcldr/arcldr_rvl.dol.
sd:/nt/arcfw.elf           - XP kernel ELF32 little-endian image. Loaded by
                              arcldr and jumped to at _start. Copied by CI from
                              Source/XPSP1/NT/base/build/ppc/ntoskrnl_le.elf.
sd:/README.md              - Testing instructions (WII_TEST_GUIDE.md content).
                              Generated by CI in the Package step.

Directory tree:

sd:/
  README.md
  nt/
    arcfw.elf
  apps/
    arcldr/
      boot.dol

CI workflow step ("Package Wii SD card layout") creates this layout:

  mkdir -p wii_sd/nt
  mkdir -p wii_sd/apps/arcldr
  cp entii/arcldr/arcldr_rvl.dol wii_sd/apps/arcldr/boot.dol
  cp Source/XPSP1/NT/base/build/ppc/ntoskrnl_le.elf wii_sd/nt/arcfw.elf
  (wii_sd/README.md written with testing instructions)

The wii_sd/ contents are then copied to the root of a FAT32 SD card for
real-hardware testing.
